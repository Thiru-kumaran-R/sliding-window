Pattern 01

Fixed Size Window

The window size k never changes. Slide it one step at a time: add the incoming element on the right, drop the outgoing element on the left, and update the answer from the running total — no inner loop required.

Use when the problem gives you an exact window size k.
ready arr = [2, 1, 5, 1, 3, 2], k = 3 → max sum of any window
1 / 1

Press play to begin.

def max_sum_fixed_window(arr, k):
    window_sum = sum(arr[:k])
    best = window_sum
    for right in range(k, len(arr)):
        window_sum += arr[right] - arr[right - k]
        best = max(best, window_sum)
    return best
static int maxSumFixedWindow(int[] arr, int k) {
    int windowSum = 0;
    for (int i = 0; i < k; i++) windowSum += arr[i];
    int best = windowSum;
    for (int right = k; right < arr.length; right++) {
        windowSum += arr[right] - arr[right - k];
        best = Math.max(best, windowSum);
    }
    return best;
}

Pattern 02

Variable Window — Longest / Maximum

Expand right on every step. Only shrink from the left when the window becomes invalid. Because the loop guarantees a valid window right after it exits, record the answer after the shrink loop.

Use when the problem asks for the longest / maximum-length substring or subarray satisfying a condition.
ready s = "ABCABCBB" → longest substring without repeating characters
1 / 1

Press play to begin.

def longest_unique_substring(s):
    seen = set()
    left = 0
    best = 0
    for right in range(len(s)):
        while s[right] in seen:
            seen.remove(s[left])
            left += 1
        seen.add(s[right])
        best = max(best, right - left + 1)
    return best
static int longestUniqueSubstring(String s) {
    Set seen = new HashSet<>();
    int left = 0, best = 0;
    for (int right = 0; right < s.length(); right++) {
        while (seen.contains(s.charAt(right))) {
            seen.remove(s.charAt(left));
            left++;
        }
        seen.add(s.charAt(right));
        best = Math.max(best, right - left + 1);
    }
    return best;
}

Pattern 03

Variable Window — Shortest / Minimum

Expand right until the window becomes valid. Then shrink from the left for as long as it stays valid, recording the answer inside the shrink loop — you want to capture every valid moment before it breaks.

Use when the problem asks for the shortest / minimum-length substring or subarray satisfying a condition.
ready nums = [2, 3, 1, 2, 4, 3], target = 7 → shortest subarray with sum ≥ target
1 / 1

Press play to begin.

def shortest_subarray_at_least(nums, target):
    left = 0
    window_sum = 0
    best = float('inf')
    for right in range(len(nums)):
        window_sum += nums[right]
        while window_sum >= target:
            best = min(best, right - left + 1)
            window_sum -= nums[left]
            left += 1
    return best if best != float('inf') else 0
static int shortestSubarrayAtLeast(int[] nums, int target) {
    int left = 0, windowSum = 0, best = Integer.MAX_VALUE;
    for (int right = 0; right < nums.length; right++) {
        windowSum += nums[right];
        while (windowSum >= target) {
            best = Math.min(best, right - left + 1);
            windowSum -= nums[left];
            left++;
        }
    }
    return best == Integer.MAX_VALUE ? 0 : best;
}

Pattern 04

At Most K

Keep the window valid by construction: whenever the tracked count exceeds k, shrink until it doesn't. The window is always ≤ K right after the shrink loop — perfect for both "longest window with at most K" and, combined with a subtraction trick, for counting subarrays.

Use when the condition is "at most K distinct / odd / zero elements", etc.
ready s = "eceba", k = 2 → longest substring with at most 2 distinct characters
1 / 1

Press play to begin.

def longest_at_most_k_distinct(s, k):
    if k == 0:
        return 0
    count = {}
    left = 0
    best = 0
    for right in range(len(s)):
        count[s[right]] = count.get(s[right], 0) + 1
        while len(count) > k:
            count[s[left]] -= 1
            if count[s[left]] == 0:
                del count[s[left]]
            left += 1
        best = max(best, right - left + 1)
    return best
static int longestAtMostKDistinct(String s, int k) {
    if (k == 0) return 0;
    Map count = new HashMap<>();
    int left = 0, best = 0;
    for (int right = 0; right < s.length(); right++) {
        char c = s.charAt(right);
        count.put(c, count.getOrDefault(c, 0) + 1);
        while (count.size() > k) {
            char lc = s.charAt(left);
            count.put(lc, count.get(lc) - 1);
            if (count.get(lc) == 0) count.remove(lc);
            left++;
        }
        best = Math.max(best, right - left + 1);
    }
    return best;
}

Pattern 05

At Least K / Exactly K

For counting-type conditions there's rarely a direct "at least K" window — instead lean on the identity exactly(K) = atMost(K) − atMost(K−1). The visualizer below runs the atMost engine live, then subtracts a silently-computed atMost(K−1) to get the final answer.

Use when counting subarrays with exactly / at least K distinct or matching elements.
ready nums = [1, 1, 2, 1, 1], k = 3 → count of subarrays with exactly 3 odd numbers

def number_of_nice_subarrays(nums, k):
    def at_most(k):
        if k < 0:
            return 0
        left = 0
        odd_count = 0
        result = 0
        for right in range(len(nums)):
            if nums[right] % 2 != 0:
                odd_count += 1
            while odd_count > k:
                if nums[left] % 2 != 0:
                    odd_count -= 1
                left += 1
            result += (right - left + 1)
        return result

    return at_most(k) - at_most(k - 1)
static int numberOfSubarrays(int[] nums, int k) {
    return atMost(nums, k) - atMost(nums, k - 1);
}

private static int atMost(int[] nums, int k) {
    if (k < 0) return 0;
    int left = 0, oddCount = 0, result = 0;
    for (int right = 0; right < nums.length; right++) {
        if (nums[right] % 2 != 0) oddCount++;
        while (oddCount > k) {
            if (nums[left] % 2 != 0) oddCount--;
            left++;
        }
        result += (right - left + 1);
    }
    return result;
}

Pattern 06

Monotonic Deque

To track the max (or min) of every window in O(n) total, keep a deque of indices whose values are strictly decreasing. Pop smaller values from the back before pushing (they can never win again), and pop the front once it falls outside the window.

Use when you need the running max/min of every window of size k.
ready nums = [1, 3, -1, -3, 5, 3, 6, 7], k = 3 → max of every window
1 / 1

from collections import deque

def sliding_window_max(nums, k):
    dq = deque()  # stores indices, values strictly decreasing
    result = []
    for right in range(len(nums)):
        while dq and nums[dq[-1]] < nums[right]:
            dq.pop()
        dq.append(right)
        if dq[0] <= right - k:
            dq.popleft()
        if right >= k - 1:
            result.append(nums[dq[0]])
    return result
static int[] slidingWindowMax(int[] nums, int k) {
    Deque dq = new ArrayDeque<>();
    int n = nums.length;
    int[] result = new int[n - k + 1];
    int idx = 0;
    for (int right = 0; right < n; right++) {
        while (!dq.isEmpty() && nums[dq.peekLast()] < nums[right]) dq.pollLast();
        dq.addLast(right);
        if (dq.peekFirst() <= right - k) dq.pollFirst();
        if (right >= k - 1) result[idx++] = nums[dq.peekFirst()];
    }
    return result;
}

Decision Cheat Sheet

A quick lookup for which pattern to reach for once you spot the signal in a problem statement.

Signal in the problemPattern to use
"subarray of size k"Fixed size window
"longest substring / subarray satisfying X"Variable window — longest, shrink while invalid
"smallest / minimum subarray satisfying X"Variable window — shortest, shrink while valid
"at most K distinct / odd / zero…"At Most K engine
"exactly K" or "at least K" (counting)atMost(K) − atMost(K−1)
"max / min in every window"Monotonic deque
Anagram / permutation matchingHash map frequency window
Maximum window

Shrink while invalid, then measure. The while-loop guarantees the window is valid the moment it exits, so record the result right after it.

Minimum window

Shrink while valid, measuring each step. You're squeezing a valid window tighter, so record before it breaks — inside the loop.

At most K

Always keep the window ≤ K. Count subarrays ending at right by adding right − left + 1 once the window is valid again.

At least / exactly K

Flip it into a subtraction against atMost. There's rarely a clean direct window for these — build on the engine you already have.
